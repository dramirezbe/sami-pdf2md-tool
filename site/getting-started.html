Getting Started

Install SAMI and convert your first PDF in under a minute.

Install

Linux / macOS

curl -fsSL https://raw.githubusercontent.com/dramirezbe/sami-pdf2md-tool/main/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/dramirezbe/sami-pdf2md-tool/main/install.ps1 | iex

From source (developers)

git clone https://github.com/dramirezbe/sami-pdf2md-tool.git
cd sami-pdf2md-tool
uv tool install --python 3.12 -e .

Update to latest version

sami upgrade

Or re-run the install command — it detects an existing installation and updates it.

Requirements: Python 3.11–3.13. The installer handles Python via uv automatically. No Docker or API keys needed.

Quick start

Convert a single PDF:

sami paper.pdf

This creates a paper/ folder next to the PDF containing paper.md and any extracted figures.

Convert multiple PDFs:

sami paper1.pdf paper2.pdf report.pdf

Convert all PDFs in a folder:

sami ~/Documents/papers/ --recursive

sami [convert] <INPUT...>

The main command. convert is implicit — sami paper.pdf and sami convert paper.pdf are identical.

Accepts one or more PDF files or directories. Directories are scanned for .pdf files (add --recursive for subfolders).

Conversion modes

ModeLayout engineSpeedQualityGPU needed
fastRF-DETRFastGoodNo
balancedMarker + TorchModerateBetterOptional (CUDA)
qualityVLM via llama.cppSlowerBestOptional (CUDA)

fast uses RF-DETR for layout detection. CPU only, no GPU needed. Good for simple documents without complex tables.

balanced (default) uses the Marker engine with Torch-based layout. Uses CUDA if available, falls back to CPU automatically.

quality uses VLM layout detection through a local llama.cpp server. GPU layers are scaled to available VRAM:

  • ≥ 8 GB VRAM: full layer offload, fast
  • 4–8 GB: partial offload, slower
  • < 4 GB or no GPU: CPU inference, works on any machine
Hardware never changes the requested mode. If the GPU is insufficient, SAMI warns and continues in the same mode on CPU.

sami health

Check the installation status without changing anything.

sami health

Reports the CLI version, protocol version, and readiness of each conversion mode. Use --json for machine-readable output.

sami health --json

sami doctor

Extended diagnostics including installation record, compatibility profile, model paths, and device info.

sami doctor
sami doctor --json

sami setup

Download models and validate that all conversion modes are ready. Runs automatically on first install; use it after to repair or verify.

sami setup
FlagDescription
--jsonMachine-readable JSON output.
--forceRe-validate even if the installation is already ready.
--register-onlyRecord the launcher path without downloading models.
--executable PATHRegister a specific launcher path.

sami upgrade

Update SAMI in its current environment, reusing compatible dependencies.

sami upgrade
sami upgrade --ref v0.3.1
FlagDescription
--ref REFGit branch, tag, or commit to upgrade to. Defaults to the installed ref or main.

Output structure

By default, each PDF produces a subfolder with the same name:

sami report.pdf
# report/
#   report.md        ← Markdown with LaTeX equations and tables
#   figure_1.png     ← extracted figures
#   figure_2.png

With --output:

sami report.pdf -o converted/
# converted/report/
#   report.md
#   figure_1.png

With --flat (no subfolder):

sami report.pdf --flat -o out/
# out/
#   report.md
#   report_figure_1.png

GPU support

SAMI detects CUDA GPUs automatically via --device auto (the default). Override with:

sami paper.pdf --device cpu     # force CPU
sami paper.pdf --device cuda    # force CUDA
sami paper.pdf --device rocm    # force ROCm (AMD)

All three modes are fully local and keyless. No Docker, no API keys.

  • fast: CPU only, no GPU needed.
  • balanced: Torch-based — uses CUDA if available.
  • quality: llama.cpp — GPU layers scale to available VRAM. Falls back to CPU with -ngl 0.

Examples

Basic conversion

sami paper.pdf

Fast mode for quick results

sami paper.pdf --mode fast

Quality mode for complex documents

sami paper.pdf --mode quality

Custom output directory

sami paper.pdf -o ~/converted/

Batch convert an entire folder

sami ~/Documents/papers/ --recursive -o ~/markdown/

Flat output (no subfolders)

sami *.pdf --flat -o out/

Quiet mode in scripts

sami paper.pdf -q && echo "Done"

Force CPU on a machine with GPU

sami paper.pdf --device cpu

JSON output for automation

sami paper.pdf --json 2>/dev/null | jq '.event'

Check installation health

sami health --json | jq '.modes'

Upgrade to a specific version

sami upgrade --ref v0.3.1

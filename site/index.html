PDF to Markdown.
Local. No keys.

SAMI converts your PDFs into clean, structured Markdown with extracted figures. Runs entirely on your machine.

Windows (.exe) Linux (.deb) Linux (.AppImage) macOS (.dmg)

$ sami paper.pdf

$ sami report.pdf --mode fast
# Fast mode, CPU only
 
$ sami *.pdf -o converted/
# Batch convert to custom directory

Why SAMI

🔒

Completely local

Your documents never leave your machine. No uploads, no cloud, no API keys.

⚡

Three conversion modes

Fast for speed, Balanced for accuracy, Quality for complex tables and VLM layout detection.

🖼

Figures extracted

Images and figures are automatically extracted alongside your Markdown output.

💻

Desktop app

Drag-and-drop GUI for Windows and Linux. Preview PDFs and Markdown side by side.

🆘

GPU acceleration

Automatic CUDA detection. Falls back to CPU gracefully with zero configuration.

📦

One-line install

Single command on Linux, macOS, and Windows. Handles Python, dependencies, and models.

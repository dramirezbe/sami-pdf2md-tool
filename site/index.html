Get started

Terminal Install

One command installs the CLI and the desktop app. No prerequisites.

curl -fsSL https://github.com/dramirezbe/sami-pdf2md-tool/releases/latest/download/install.sh | bash
irm https://github.com/dramirezbe/sami-pdf2md-tool/releases/latest/download/install.ps1 | iex
git clone https://github.com/dramirezbe/sami-pdf2md-tool.git && cd sami-pdf2md-tool && uv tool install --python 3.12 -e .

Why SAMI

Built for researchers and developers

Convert academic papers, reports, and documentation to Markdown that works with your tools.

Completely private

Your documents never leave your machine. No uploads, no cloud processing, no API keys to manage.

Three conversion modes

Fast for quick results, Balanced for accuracy, Quality for complex tables and VLM-powered layout.

Figures extracted

Images and figures are automatically extracted alongside your Markdown — ready for Obsidian, Notion, or Git.

Desktop app included

Drag-and-drop GUI for Windows and Linux. Preview your PDF and Markdown side by side.

GPU acceleration

Auto-detects CUDA GPUs and scales layers to available VRAM. Falls back to CPU with zero config.

Batch processing

Convert entire folders with --recursive. Process hundreds of PDFs with a single command.

Conversion

Pick the right mode for your documents

Each mode trades speed for accuracy. All three run entirely on your machine.

--mode fast
RF-DETR engine
⚡ Fast Good quality No GPU needed
--mode balanced
Marker + Torch
Moderate speed Better quality GPU optional
--mode quality
VLM (llama.cpp)
Slower Best quality GPU optional
